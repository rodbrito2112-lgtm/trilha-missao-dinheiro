# Trilha Missão Dinheiro Club

Protótipo jogável (v3.3) do jogo de educação financeira do Missão Dinheiro Club, em versão instalável (PWA).

- Abra o link do GitHub Pages no celular e toque em "Instalar" (Android) ou em Compartilhar > Adicionar à Tela de Início (iPhone).
- O progresso fica salvo no aparelho. O jogo envia dados de uso sem nome (tipo de aparelho, faixa, perfil opcional e resumo semanal) para melhorar a experiência; o envio pode ser desligado no rodapé, o que apaga esses dados do servidor. O jogo não usa dinheiro de verdade.
