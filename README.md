# Trilha Missão Dinheiro Club

Protótipo jogável (v3.0) do jogo de educação financeira do Missão Dinheiro Club, em versão instalável (PWA).

- Abra o link do GitHub Pages no celular e toque em "Instalar" (Android) ou em Compartilhar > Adicionar à Tela de Início (iPhone).
- O progresso fica salvo no aparelho. No piloto, com o código da família, um resumo semanal sem nome e uma cópia de segurança do progresso vão para a equipe do projeto. O jogo não usa dinheiro de verdade.
