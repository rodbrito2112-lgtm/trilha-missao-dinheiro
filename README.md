# Trilha Missão Dinheiro Club

Protótipo jogável (v2.7) do jogo de educação financeira do Missão Dinheiro Club, em versão instalável (PWA).

- Abra o link do GitHub Pages no celular e toque em "Instalar" (Android) ou em Compartilhar > Adicionar à Tela de Início (iPhone).
- O progresso fica salvo só no aparelho. O jogo não coleta dados nem usa dinheiro de verdade.
